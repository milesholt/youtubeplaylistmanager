Playlist Cleaner

One-time setup

This app talks to YouTube through your own Google Cloud project, so nothing is shared with anyone else.

How to get a Client ID
  1. Open console.cloud.google.com and create a project.
  2. Go to APIs & Services → Library and enable YouTube Data API v3.
  3. OAuth consent screen: choose External, fill in the basics, and add your own Google account under Test users.
  4. Credentials → Create credentials → OAuth client ID, type Web application.
  5. Under Authorized JavaScript origins add the address this page is hosted at (for example ), with no path.
  6. Copy the Client ID and paste it below.

Client ID

Sign in with the Google account that owns the playlists.
